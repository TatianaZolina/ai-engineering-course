# Внутренний регламент предприятия «ПромТех»:  
**«Регламент реагирования на инциденты на технологических установках»**

## **Шапка документа**

```
# Название документа: Регламент реагирования на инциденты на технологических установках

Наименование предприятия: ПромТех  
Номер документа: РГЛ-РИ-007  
Версия: 3.1  
Дата утверждения: 01.09.2023  
Дата вступления в силу: 01.10.2023  
Утверждён руководителем службы промышленной безопасности  
Область действия: Производственные цеха №1–№4, объекты производства А, Б, В  
Периодичность пересмотра: раз в три года
```

## **Содержание документа**

### 1. Назначение и область применения

#### Проверяемые факты:
- Инцидент классифицируется как отклонение от норм технологического режима работы установки (ТРИ 1.1);
- Ответственная служба — отдел промышленной безопасности (ОПБ), ответственное лицо — инженер по ПБ (Ф.И.О.);
- Перечень объектов, подлежащих обязательному контролю, указан в приложении №1 (РГЛ-Ф-01).

### 2. Порядок действий персонала при обнаружении инцидента

#### Проверяемые факты:
- Время оповещения вышестоящего руководства — не позднее 15 минут после обнаружения события (ТРИ 2.2);
- Формы уведомления — телефонная связь, электронная почта, форма РГЛ-Ф-02;
- Срок регистрации инцидента в журнале учета инцидентов — не позднее одного рабочего дня (ТРИ 2.3).

### 3. Организация мероприятий по локализации и ликвидации последствий инцидента

#### Проверяемые факты:
- План мероприятий по устранению инцидента разрабатывается в течение двух часов после получения сигнала (ТРИ 3.1);
- Ликвидатором назначается ответственный сотрудник смены (ФИО сотрудника), утвержденный приказом руководителя смены;
- Оценка ущерба производится комиссией в составе начальника смены, инженера по охране труда и представителя отдела ПБ (ТРИ 3.2).

### 4. Требования к проведению расследования инцидента

#### Проверяемые факты:
- Расследование инцидента должно проводиться комиссией в течение трех рабочих дней (ТРИ 4.1);
- Форма отчета о расследовании инцидента — форма РГЛ-Ф-03;
- Результаты расследования фиксируются в электронном журнале учета инцидентов (ТРИ 4.2).

### 5. Предупреждение повторения инцидентов

#### Проверяемые факты:
- Разработанные мероприятия по предупреждению повторений инцидентов утверждаются начальником цеха (ТРИ 5.1);
- Сроки выполнения корректирующих мероприятий — не позднее семи календарных дней (ТРИ 5.2);
- Контроль исполнения мероприятий осуществляет инженер по технологическому оборудованию (ФИО).

### 6. Отчетность по инцидентам

#### Проверяемые факты:
- Ежеквартальная отчетность о количестве произошедших инцидентов направляется в службу охраны труда (форма РГЛ-Ф-04);
- Годовая отчетность представляется ежегодно до 1 февраля следующего года (ТРИ 6.1);
- Срок хранения отчетов — пять лет (ТРИ 6.2).

### Исключение и особые случаи

#### Примеры исключительных ситуаций:
- Работы на оборудовании, не входящем в перечень ТРИ 1.1, регулируются отдельным регламентом РГЛ-ХХ-НН;
- Отсутствие данных о типе оборудования требует индивидуального решения инженера по эксплуатации (ТРИ 6.3).
