# ai-engineering-course

## Troubleshooting

### 401 Unauthorized — неверный ключ API

Что видел: при отправке запроса к провайдеру возникала ошибка `401 Unauthorized`, и запрос не выполнялся

Почему: провайдер отклонил запрос, поскольку ключ API оказался неверным, недействительным или не соответствовал ожидаемым учётным данным

Что сделал: проверила правильность ключа в файле `.env` и восстановила действительное значение. После этого повторно запустила скрипт и проверила, что запрос выполняется с рабочими учётными данными

### 429 Too Many Requests — превышен лимит запросов

Что видел: при обращении к провайдеру возникала ошибка `429 Too Many Requests`, и запрос не удавалось выполнить

Почему: было превышено ограничение провайдера на количество запросов за определённый промежуток времени

Что сделал: учёла ограничение на количество запросов и повторила обращение позднее, когда возможность отправки запросов восстановилась. Если ошибка повторяется, необходимо проверить ограничения и доступные лимиты провайдера
